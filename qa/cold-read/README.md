# 冷读测试说明

每章有一份测试规格 `chapter-NN.json` 和一份结果 `chapter-NN-result.json`。规格固定五个问题、一个代码或 Shape 任务、允许阅读范围、禁止依赖的后续术语和 4/5+任务的门槛。

本轮结果是受限上下文的大模型代理一致性筛查：只提供当前章及之前章节，不读取旧正文或附录。它能发现明显的术语倒置和题目依赖，但不能替代真实学习者的停顿、误解和用时反馈。

试点第 00–03 章仍建议邀请 1–2 名真实目标读者复测。真实反馈到来时，保留规格，新增或替换结果中的 `tester_type`、用时、错误与卡点，不降低自动门槛。

运行检查：

```bash
python qa/check_cold_read.py
```
