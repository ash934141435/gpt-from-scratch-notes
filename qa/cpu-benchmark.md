# CPU 快速验收基准

测试日期：2026-07-30
环境：Python 3.10.12、PyTorch 2.13.0+cpu、NumPy 2.2.6、12 个 PyTorch CPU 线程。

命令：

```bash
.venv/bin/python qa/run_code_snapshots.py
```

|---|---|---:|

| V1 | 默认 | 1.17s |
| V2 | 默认 | 1.18s |
| V3 | 默认 | 3.53s |
| V4 | 默认 | 0.92s |

| V8 | 默认 | 0.77s |
| V9 | 默认 | 0.87s |
| V10 | 默认快速配置 | 1.68s |
| V11 | `--smoke-test` | 1.63s |

总时间 **14.24 秒**。12 个版本全部低于单文件 120 秒上限，全套低于约 3 分钟目标。

V11 烟雾测试实际执行了固定 train/val 评估、perplexity 输出、checkpoint 保存、用新模型实例加载、temperature=1.0 与 top-k=10 采样；没有运行默认 200 步完整训练。

墙钟时间会随磁盘缓存、CPU、线程数和系统负载变化，本表只证明当前环境的快速验收规模可接受，不是性能承诺。
