# 字幕语义第二轮复核

## 复核方法

本轮不再把“字幕落入某个时间范围”直接视为“正文已覆盖”。每个 M001–M164 微段分别对照：

1. 该时间范围内的自动字幕原文；
2. 相邻微段的重叠字幕，避免滚动字幕跨边界时丢掉后半句；
3. 正文中的“这一段在做什么”和“字幕语义讲解”；
4. 画面中的代码、运行结果或架构图；
5. 涉及代码时的 shape、模型作用和错误后果。

人工确认结果记录在 `semantic-review.csv`。只有存在一条 `已人工复核` 记录且备注非空时，`build_full_indexes.py` 才会把对应字幕写成 `已覆盖并人工复核`；其他情况保持 `已归属，待语义复核`，并使总检查失败。

## 自动字幕边界处理

YouTube JSON3 字幕是滚动窗口，不是互不重叠的完整句子。当前有 325 个字幕事件的结束时间跨过微段边界。处理原则是：

- 覆盖表仍按开始时间给事件一个主要归属，避免重复统计；
- 人工复核时同时阅读前后两个微段的字幕；
- 如果一句话承担主题过渡，前段解释旧结论，后段解释新操作；
- 纯重复滚动文本不在正文重复翻译。

因此，2,955 是字幕事件索引数量，不等于 2,955 个独立句子。

## 本轮重点补强

第二轮发现并扩写了以下高风险薄弱段：

| 微段 | 补强内容 |
|---|---|
| M058 | 前缀平均的逐通道数字例子、信息损失和错误维度 |
| M063 | 视频中的 14、16 点积逐项计算、shape 和运算符误用 |
| M065 | 下三角逐行归一化、`keepdim` 广播和静默逻辑错误 |
| M067 | 两行向量化代码的语法、数学、模型三层作用和运行断言 |
| M077 | `n_embd` 重构前后完整对比、参数 shape、错误后果和新视频截图 |
| M084 | 零分数产生均匀权重的原因和内容相关权重数字例子 |
| M095 | 自回归有向图、邻接矩阵和未来信息泄漏 |
| M096 | 置换等变性，以及位置编码、mask、Q/K 的职责边界 |
| M114 | 优化困难与过拟合的区别、梯度连乘和排查顺序 |
| M117 | `I + dF/dx`、恒等梯度实验及“高速公路”类比边界 |

同时修正了 M029、M070、M097 中“batch 只用于并行”的不完整表述：前向注意力不跨样本通信，但多个样本会共同贡献一次参数更新的梯度。

## 结果

- M001–M164：164 个微段均有唯一人工复核记录；
- 字幕事件：2,955 条均变为 `已覆盖并人工复核`；
- 纯结束语 M164：记录时间归属，不强行制造新知识；
- 复核记录包含具体检查备注，不再使用自动生成的统一“完成”状态。
