# 第 17 章：从预训练到 ChatGPT 式助手

`source_mode=video` · 视频 1:49:00–1:56:20 · M149–M164 · 预计 2–3 小时

## 1. 本章只解决什么问题

本章把 V10 放进更大的训练地图：预训练先得到文档续写器；历史上的助手流程再使用监督微调（SFT）、偏好排序、奖励模型和 PPO 塑造行为。这里只讲概念，不新增 SFT、奖励模型或 PPO 代码。

## 2. 学习前检查

你需要能说明 V10 的训练目标是预测下一个 token，并能区分模型参数量、一次序列长度和训练数据 token 数。不会强化学习也可以开始。

## 3. 不使用术语的直观例子

一个读完大量网页的人会续写很多文档格式，但你问问题时，他也可能继续写“下一个问题”，因为训练只要求像网页后续。要把他变成助手，还要给他看理想问答、比较多份答案哪个好，并用这些偏好继续调整行为。

```text
大量普通文本
  → 下一 token 预训练
  → 文档续写器
  → 高质量问答示范（SFT）
  → 助手式模型
  → 人类对多个回答排序
  → 奖励模型近似偏好
  → PPO 等方法继续优化
  → 历史上的 RLHF 助手流程
```

这张图是 2022 年 InstructGPT 论文及原视频讲述的历史流程，不是 2026 年所有系统的固定配方。

方法与数值的来源日期：

## 5. 跟着完成最小代码

这里只用数量级计算防止混淆指标：

```python
course_parameters = 10_000_000
gpt3_parameters = 175_000_000_000
course_tokens_estimate = 300_000
gpt3_tokens = 300_000_000_000

print("parameter ratio:", gpt3_parameters / course_parameters)
print("training-token ratio:", gpt3_tokens / course_tokens_estimate)
```

得到约 17,500 倍参数和 1,000,000 倍训练 token。这些是视频中的数量级比较；课堂字符数换算成 subword token 只是粗估，不是精确测量。

## 6. 每行代码在做什么

- 参数量：模型中可学习数字的总数。
- token 数：训练过程读过多少离散文本单位；同一文本换 tokenizer 会改变计数。
- 训练计算量：由模型、token、前后向和硬件效率共同决定，不能只用参数量代替。
- 硬件规模：设备数量与类型；更多 GPU 还带来通信、数据吞吐和故障恢复问题。

四个后训练概念：

- SFT：用理想输入—回答示范继续做 token 预测，塑造助手格式和行为。
- 偏好排序：让标注者对同一提示的多个候选回答排序。
- 奖励模型：学习把提示与回答映射成近似人类偏好的分数。
- PPO：一种强化学习优化方法，在视频历史流程中用奖励分数继续调整生成策略。

## 7. Shape 变化卡片

本章重点是流程，不新增模型 Shape。SFT 仍可使用熟悉的数据形式：

```text
输入 token IDs                   [B,T]
模型 logits                     [B,T,V]
回答位置 targets                [B,T]
对不计分位置使用 loss mask      [B,T]
平均后 loss                     []
```

“后训练”并不自动改变 Transformer Block 的输入输出 Shape；主要变化是数据、损失计算范围和优化目标。

## 8. 为什么这样设计

预训练覆盖大量通用文本，建立语言与模式能力，但它只奖励匹配文本分布。SFT 用少量高质量助手示范选择行为方向。偏好阶段能表达“不只有一个逐字标准答案，但某些回答更好”。

奖励模型与 PPO 只是把偏好用于优化的一种历史路线。直接偏好目标、由模型参与反馈等方法也属于后续研究范围；它们随时间变化，本课程不展开，也不把阶段名当成能力保证。

模型外系统同样重要：检索、工具调用、系统提示、内容过滤和产品界面不会因为你实现了 V10 自动出现。

## 9. 常见误解与报错

- 10M 参数、1M 字符和 300K subword token 是三种不同量。
- “架构相近”不表示训练成本相近；工业预训练还包括大规模数据和分布式系统。
- 预训练模型不是乱码生成器，但也不会自动稳定服从指令。
- SFT 不需要发明新的 Attention 公式；它主要改变训练数据与目标位置。
- 奖励模型分数不是真理，只是对收集到偏好的近似。
- PPO 是视频/2022 论文中的阶段，不应宣称为所有现代系统固定实现。
- 完成本课程并没有实现任何这些后训练阶段。

## 10. 完整示范

用同一提示区分三种数据：

```text
预训练文本：网页中自然出现的“问：……答：……”或任意文档片段
SFT 示例：用户问题 + 人工写的理想助手回答
偏好数据：同一问题 + 回答 A/B/C + 从好到差的排序
```

它们都可以被编码成 token，但产生方式和训练用途不同。
