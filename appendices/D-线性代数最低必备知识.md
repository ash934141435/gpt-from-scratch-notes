# 附录 D：线性代数与概率最低必备知识

目标不是补完一门大学课程，而是让你能独立解释本视频每个关键表达式。

## 1. 向量：一个 token 的一组特征

向量可先看成一列有顺序的数字：

```text
x = [2, -1, 0.5]
```

它有 3 个分量，所以是 3 维向量。Embedding 的每个 token 表示就是 C 维向量；具体维度含义由训练学习，不是人工给每维命名。

两个同维向量可逐元素相加：

```text
[2,-1] + [3,4] = [5,3]
```

这解释了 token embedding 与 position embedding 相加，以及残差 `x + F(x)` 为什么要求 shape 相同。

## 2. 点积：把两个向量的匹配压成一个数

点积是对应分量相乘后求和：

```text
[a,b] · [c,d] = a*c + b*d
```

例子：

```text
[2,0] · [3,0] = 6
[2,0] · [0,4] = 0
```

Self-Attention 用 query 与 key 点积得到匹配分数。分数大表示在当前学习到的特征空间中方向更相容；它还不是概率。

点积要求两个向量长度相同，这就是 q/k 最后一维都必须为 H 的原因。

## 3. 矩阵乘法：批量计算加权和

矩阵 A 的第 i 行与矩阵 B 的第 j 列做点积，得到输出第 `[i,j]` 项。

```text
A [M,K] @ B [K,N] → C [M,N]
```

共同维 K 被逐项相乘并求和，所以消失。

例子：

```text
A = [[1,0],       B = [[3,4],
     [1,1]]            [5,6]]

A @ B = [[3,4],
         [8,10]]
```

A 第一行只取 B 第一行；第二行把 B 两行相加。由此可把左矩阵每一行理解为“如何混合右矩阵各行”的配方。

## 4. 下三角矩阵：把因果可见范围写进权重

T=4 时：

```text
[[1,0,0,0],
 [1,1,0,0],
 [1,1,1,0],
 [1,1,1,1]]
```

第 t 行只有 0…t 为 1，因此乘 token 矩阵后只包含自己和过去。对每行除以行和：

```text
[[1,  0,  0,  0],
 [1/2,1/2,0,  0],
 [1/3,1/3,1/3,0],
 [1/4,1/4,1/4,1/4]]
```

它就从前缀和变成前缀平均。

## 5. 加权平均：Attention 输出的直接含义

若注意力一行为 `[0.25,0.75]`，value 为：

```text
v0 = [4,0]
v1 = [0,8]
```

则：

```text
out = 0.25*v0 + 0.75*v1 = [1,6]
```

权重决定从每个源位置取多少，value 决定实际传输什么。

## 6. 指数与 Softmax

指数函数 `exp(x)` 始终为正，且放大差异：

```text
exp(0)=1
exp(1)≈2.718
exp(-∞)=0
```

Softmax 对一行 logits `z` 计算：

```text
softmax(z_i) = exp(z_i) / Σ_j exp(z_j)
```

所以输出非负、总和为 1。例子：

```text
z = [0,0] → [0.5,0.5]
z = [0,-∞] → [1,0]
```

这解释了：

- 允许位置分数全 0 会得到均匀权重；
- mask 必须填 `-inf`，填 0 仍有概率；
- logits 绝对值很大时，softmax 容易接近 one-hot。

## 7. 对数与 Cross-Entropy

对正确类别概率 p，单样本负对数损失为：

```text
loss = -log(p)
```

```text
p=1.0  → loss=0
p=0.5  → loss≈0.693
p=0.01 → loss≈4.605
```

模型对正确 token 越自信，loss 越低。若 V 个类别初始均匀：

```text
p=1/V
loss=-log(1/V)=log(V)
```

本课 V=65，所以随机均匀基线约为 `ln(65)≈4.17`。

## 8. 均值、方差与标准差

均值：

```text
mean(x) = Σx_i / N
```

方差衡量数值围绕均值的离散程度：

```text
variance(x) = mean((x_i - mean(x))²)
```

标准差为方差平方根。LayerNorm 使用：

```text
x_hat = (x - mean) / sqrt(variance + eps)
```

`eps` 防止方差接近 0 时除零。

## 9. 为什么 QK 要乘 `1/√H`

假设 q、k 的每个分量均值约 0、方差约 1。点积是 H 个乘积之和；在近似独立条件下，和的方差约为 H。

乘以 `1/√H` 后：

```text
Var((q·k)/√H) ≈ H / H = 1
```

这使不同 head size 下 logits 尺度接近，避免 H 很大时 softmax 在初始化阶段过度尖锐。

## 10. 梯度：函数在当前位置的局部斜率

若 `y = x²`，则 `dy/dx = 2x`。在 x=3 附近，x 增加一点，y 约增加 `6×那一点`。

神经网络梯度回答：“每个参数微小变化，会让 loss 怎样变化？”优化器沿能降低 loss 的方向更新。

链式法则让梯度穿过多层函数：

```text
x → f(x) → g(f(x)) → loss
```

反向传播把各局部导数相乘并累积。

## 11. 残差连接为何有梯度直路

```text
y = x + F(x)
dy/dx = 1 + dF/dx
```

常数 1 来自 identity 分支。即使复杂分支的导数很小，梯度仍可直接传回 x。这不是“保证任何深网都不会梯度消失”，但显著改善可优化性。

## 12. 广播不是矩阵乘法

广播是逐元素运算前对缺失维度的逻辑复用：

```text
[B,T,C] + [T,C] → [B,T,C]
```

矩阵乘法则沿共同 K 维做乘加：

```text
[B,T,H] @ [B,H,T] → [B,T,T]
```

两者都可能“自动处理 batch”，但数学操作完全不同。

## 13. 线性变换与非线性

线性层（严格说带 bias 时是仿射变换）：

```text
y = xW + b
```

连续两个无非线性的线性层可合并：

```text
(xW1)W2 = x(W1W2)
```

加入 ReLU/GELU 后不能这样合并，因此 MLP 能表达更复杂的分段关系。

## 14. 概率采样与贪心选择

若概率为 `[0.7,0.2,0.1]`：

- 贪心：永远选择第一个；
- 随机采样：长期约 70%/20%/10% 选择三项。

本课 `multinomial` 使用随机采样，所以相同 prompt 可产生不同文本。随机性不表示模型没有学到概率结构。

## 15. 你应该能独立推导的五条式子

```text
1. [B,T,C] + [T,C] → [B,T,C]
2. [B,T,H] @ [B,H,T] → [B,T,T]
3. [B,T,T] @ [B,T,H] → [B,T,H]
4. nh × [B,T,H] --cat--> [B,T,C]
5. [B,T,C] → FFN [B,T,4C] → [B,T,C]
```

如果其中任何一条还只能背答案，回到 [Shape 速查](./B-张量与Shape速查.md)，为每个维度写出“谁被求和、谁被保留、谁表示什么”。
